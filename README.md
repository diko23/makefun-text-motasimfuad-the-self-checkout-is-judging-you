Entry for the [The Self-Checkout Is Judging You](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6) competition on make.fun.

## Entry overview

`main.ts` writes a single-line remark (115 characters, UTF-8) spoken in the voice of a smug self-checkout machine silently sizing up the contrast between a shopper's aspirational healthy produce and their family-size snack purchase.

## Run it

```sh
node main.ts
```

By default `main.ts` writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when `MAKEFUN_OUTPUT_DIR` is set), exits `0` with no stdout output on success, and exits non-zero on error. The grader runs it as `node /bot/main.ts`.
